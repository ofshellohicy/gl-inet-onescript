# GL-MT3000

## 摘要

GL-MT3000 是本项目完成 OpenClash 双配置无扰导入验证的 GL.iNet 路由器。2026-08-18 实机使用 `mediatek/mt7981` 目标和 `aarch64_cortex-a53` 包架构。

## 已验证状态

- OpenClash `0.47.088` 正常运行。
- Linux ARM64 Mihomo 核心可解析并运行 VLESS Reality、Vision 和 XUDP 配置。
- 第二套完整 YAML 可以在不修改活动配置、不重启 OpenClash 的情况下加入配置管理。
- LuCI 的配置管理页面可显示两套配置并供后续切换。
- 第二配置切换和 Apply 后启动成功，活动代理实测出口国家为美国。
- 活动核心旁的第二个完整 GeoSite 校验进程会造成 OOM，通用脚本已改用轻量校验副本。
- OpenClash Fake-IP 模式下对 `captive.apple.com` 同时设置 Fake-IP 排除和置顶直连后，已完成本地 DNS/HTTP 验证及真实酒店认证测试。
- Microsoft NCSI 后缀已排除 Fake-IP，Windows 新旧四条 HTTP 探测主机也已精确直连；运行时与 IPv4 DNS/HTTP 验证通过，IPv6 链路和酒店现场仍待测试。
- Linux 继续按客户端 NetworkManager URI 动态识别，没有硬编码全发行版域名。
- 当前 LAN 未发现 RFC 8910 CAPPORT DHCP/RA 选项或 RFC 8908 API；设备实现的是传统探测兼容，不是 CAPPORT 服务端。

以上版本和平台信息是一次实机快照，固件升级后应重新检查。
